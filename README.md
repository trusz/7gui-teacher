# 7GUIs Frontend Teaching Repository

This repository helps students practice browser UI development through the classic **7GUIs** benchmark tasks.

The goal is learning frontend fundamentals by building small, focused apps and understanding tradeoffs in state, events, validation, constraints, async behavior, and change propagation.

## How to use this repo

- Pick a task folder.
- Read its `Readme.md` for requirements.
- Implement in the task's `solution/` folder using your chosen web stack (vanilla JS/TS, React, Vue, Svelte, etc.).
- Use the teaching agent in guidance mode (`/teachme {technology}`) to get documentation-first help.
